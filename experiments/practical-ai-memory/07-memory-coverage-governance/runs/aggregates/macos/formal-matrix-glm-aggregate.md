# pilot-03 正式矩阵脱敏聚合

## 边界

- 这是冻结合成夹具上的正式矩阵：5 个任务 × 3 种条件 × 3 次重复，共 45 次隔离运行。
- 公开聚合不包含原始回答、逐次计时、执行器版本或具体模型标识；这些内容仅留在未跟踪的本地私有目录。
- 正式矩阵通过只说明该冻结合成场景中的任务、隔离运行和评分协议可稳定执行；它不支持跨模型稳定性、效率、条件优越性或替代人工治理的结论。
