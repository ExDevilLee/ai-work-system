# macOS 与 Win11 正式矩阵对照

## 对照范围

两个平台使用相同冻结夹具、Top-K 检索包、提示、评分表和模型配置：

- 每个平台 45 次正式运行，共 90 次。
- 模型：`gpt-5.6-sol`。
- 推理强度：`medium`。
- Codex CLI：`0.145.0`。
- 三个条件：`rag-only`、`rag-with-recency`、`memory-governed`。
- 每个任务与条件：`n=3`，`workspace_metrics_n=3`。

数据入口：

- [`formal-macos-gpt-5.6-sol-medium.json`](../data/formal-macos-gpt-5.6-sol-medium.json)
- [`formal-win11-gpt-5.6-sol-medium.json`](../data/formal-win11-gpt-5.6-sol-medium.json)

Win11 只回传脱敏聚合文件。私有原始事件、最终答案、评分文件、本机路径和会话标识仍保留在 Windows 设备。

## 正确性

| 平台 | 仅检索结果 | 检索加时间优先 | 检索加当前记忆治理 | 总分 |
| --- | ---: | ---: | ---: | ---: |
| macOS | 75/84 | 69/84 | 84/84 | 228/252 |
| Win11 | 75/84 | 69/84 | 84/84 | 228/252 |

两个平台的条件总分完全一致，但 15 个任务与条件组合并非逐项一致：

| 任务 | 条件 | macOS | Win11 | 差异 |
| --- | --- | ---: | ---: | ---: |
| 已批准决定 | 检索加时间优先 | 6/18 | 3/18 | -3 |
| 范围限定规则 | 检索加时间优先 | 15/18 | 18/18 | +3 |

其余 13 个分组逐项一致。两个差异净值相抵，因此不能只根据条件总分推断逐题行为完全相同。

共同结果包括：

1. 三种条件都能稳定恢复静态参考、明确写入证据的未解决冲突和历史变化。
1. `rag-only` 在两个平台都无法完整恢复批准层级和范围退出，得到 `75/84`。
1. `rag-with-recency` 在两个平台都因较新的 proposal 覆盖正式决定，尽管范围任务的完整度不同。
1. `memory-governed` 在两个平台都正确恢复状态、范围、当前动作和来源，得到 `84/84`。

两个平台的 90 次正式评分均为 `protocol_valid=true`，没有发现无依据断言或问题未要求的项目事实。

## 跨平台结论

本轮结果支持：在冻结的合成夹具、当前模型、推理强度和 CLI 下，“检索负责找回相关证据，记忆治理负责确认当前可执行状态”的正确性方向可以在 macOS 与 Win11 独立复现。

本轮结果不能证明：

- 所有 RAG 产品都缺少状态治理。
- 所有 Windows 环境、模型或 CLI 都会得到相同分数。
- 两个平台在单次回答或每个任务上的行为完全一致。
- 当前调用、字节和耗时差异来自操作系统本身。
- 轻量 `CURRENT.md` 足以解决真实大型知识库中的全部治理问题。
