# P9 Pilot-01 聚合结果

## 执行配置

- 请求模型与观察模型：`gpt-5.6-terra`
- 请求推理强度与观察推理强度：`medium`
- 平台：macOS
- 条件批次：每个条件一条隔离调用，`read-only`、`ephemeral`
- 矩阵：`5 个任务 × 3 个条件 × 3 个变体 = 45 格`

## 机械结果

| 条件 | final | 机械门禁通过 | 机械门禁失败 |
| --- | ---: | ---: | ---: |
| `prompt-only` | 15/15 | 15/15 | 0 |
| `guide-assisted` | 15/15 | 15/15 | 0 |
| `skill-workflow` | 15/15 | 15/15 | 0 |
| 合计 | 45/45 | 45/45 | 0 |

机械门禁只检查四个字段非空，并拦截未被否定的自动修改、自动晋升和静默扩大范围表达。它不是人工
质量判断，也不证明某个条件优于其他条件。

## 当前结论

当前 Pilot 证明这套合成任务、隔离条件材料和结构化输出协议可以在单一模型配置下跑通 45 格；
还没有证明程序性记忆提高正确率、减少返工或降低人工成本。下一步是逐份只读 Review，重点检查
范围边界、来源真实性、失败停止点和是否把候选规则误写成已批准规则。
