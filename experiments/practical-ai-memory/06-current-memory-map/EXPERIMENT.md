# 当前记忆地图实验协议

## 当前状态

本协议已从 [`DESIGN.md`](DESIGN.md) 提炼并冻结。实现仍在进行中；当前只建立 manifest 状态模型和仓库边界，尚未创建实验夹具、派生视图、运行器或人工页面。

## 研究问题

本 POC 分成两个相互独立的通道：

1. Agent 通道验证结构化状态投影能否提高当前状态恢复的正确性。
1. 人工通道验证在事实完全一致时，可视化地图能否帮助单名参与者完成探索性治理任务。

两个通道分别报告，不得用其中一个通道的结果为另一个通道背书。冻结的 `manifest.json` 是两者唯一的规范化事实源；所有索引、投影、状态表和地图都只是确定性派生产物。

## 状态模型

每个场景包必须表达五类状态事实：

- 当前有效：在匹配范围内可以指导行动。
- 已被替代：只用于历史解释，不得继续指导行动。
- 未解决冲突：不得静默选边，应暂停或提出复验。
- 待验证观察：不得晋升为稳定规则。
- 范围限定：不得扩大到其他平台或项目。

manifest 的状态值冻结为 `active`、`superseded`、`conflict` 和 `pending-validation`。范围限定通过 `scope` 表达。来源只能使用隔离夹具内的相对路径；关系只允许 `supersedes` 和 `conflicts-with`，且目标必须位于同一 manifest。

## Agent 通道

三个条件共享相同原始记录、任务提示和冻结事实，只改变导航或状态表达：

- `source-only`：只提供合成 Markdown 原始记录，没有独立索引或状态投影。
- `flat-index`：额外提供标题、相对路径、稳定摘要和更新时间，但不表达状态、范围或替代方向。
- `state-projection`：额外提供状态、范围、关系、当前动作边界和来源指针，不复制原始正文。

冻结任务为 `active-decision`、`superseded-rule`、`unresolved-conflict`、`scope-boundary` 和 `pending-observation`。每个任务使用独立新会话，三个条件都允许满分；条件名称本身不得成为评分依据。

执行规模冻结为：

- Pilot：`5 个任务 x 3 个条件 x 1 次 = 15 次`。
- macOS 正式矩阵：`5 个任务 x 3 个条件 x 3 次 = 45 次`。
- Win11 Level 2 兼容性 Smoke：`5 个任务 x 3 个条件 x 1 次 = 15 次`。

Pilot 只验证协议，不进入正式结果。正式矩阵开始前必须冻结 fixture、manifest、Prompt、预期答案、rubric、模型、推理强度和执行器版本。Win11 Level 2 通过后只能声明兼容性 Smoke 通过，不能声明完整正确性矩阵已跨平台独立复现。

## 人工通道

人工通道使用两套结构等价、内容不同的合成场景包：

- `state-table`：用普通表格表达主题、状态、关系、范围和来源。
- `visual-map`：用相同字段配合颜色、分组、文本状态标签和关系方向表达。

两种条件必须具有相同的状态类型和数量、问题数量和难度、来源详情能力、答案控件与文本事实完整度。地图不得增加表格没有的事实，状态也不得只依赖颜色表达。

每个条件回答 5 个问题。主要指标为正确率；总耗时、详情展开次数、答案修改次数和 1 至 5 分主观信心只作探索性描述。单人、单轮结果不做显著性检验，也不外推为普遍效率结论。

## 门禁与停止条件

以下任一情况出现时停止当前阶段：

- 派生产物与 manifest 不一致，或状态表与地图的事实集合不等价。
- 条件之间的原始事实或 Prompt 不等价。
- 普通索引泄漏状态答案，状态投影复制正文，或地图增加事实。
- Agent 访问条件外文件、真实记忆或用户级插件。
- 命令和 MCP 调用无法完整分类计量，或运行文件、计时和事件记录不完整。
- Prompt 截断、编码异常、退出码非零，或正式答案提前泄漏。
- 同一批次内模型、推理强度、CLI 或冻结夹具发生变化。

静态测试、夹具校验、事实等价检查、页面验收和隐私审计全部通过后，才能启动 15 次 Pilot。Pilot 逐份只读 Review 通过后，才能冻结并执行正式矩阵。

## 隐私与公开边界

- 所有场景只使用合成项目、规则、观察和来源。
- 模型、推理强度、Codex CLI 和平台标签写入 metadata，但不记录或公开模型 provider。
- Agent 使用独立临时目录、临时会话和 UTF-8 stdin，并关闭用户级插件。
- Agent 使用 Codex 原生隔离启动：忽略用户级配置和执行规则，只保留 CLI 认证、
  临时工作区、只读 sandbox 与关闭插件。任何运行时访问隔离夹具外文件、或无法完整
  分类计量的命令和 MCP 调用，都会使该运行失效；不可用事后猜测替代该门禁。
- 私有 `raw.jsonl`、完整 `final.md`、`stderr.log`、`score.json` 和人工逐题事件不进入公开仓库。
- 不公开用户名、账号、绝对路径、会话标识、浏览器身份、存储地址或真实记忆内容。
- 公开数据只包含脱敏聚合、合成夹具、生成与校验代码、代表样本及空白人工实验模板。

本 POC 不评价 GraphRAG、向量检索、大规模图算法或商业产品，也不预设视觉地图优于状态表。
