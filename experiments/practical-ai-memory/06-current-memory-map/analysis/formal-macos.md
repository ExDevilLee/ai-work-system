# macOS 正式矩阵分析

## 实验范围

本轮在冻结协议下完成 `5 个任务 x 3 个条件 x 3 次`，共 45 次正式运行：

- 平台：macOS。
- 模型：`gpt-5.6-sol`。
- 推理强度：`medium`。
- Codex CLI：`0.145.0`。
- 条件：`source-only`、`flat-index`、`state-projection`。
- 任务：当前决定、已替代规则、未解决冲突、范围边界与待验证观察。

45 个运行均正常退出。隔离环境有效，用户级插件关闭，运行时越界访问为 0；工作区指标覆盖完整且输出字节可靠。原始事件、完整答案、标准错误和逐次评分只保留在私有证据区。

## 正确性

| 条件 | 样本数 | 正确性 | 协议异常 | 无依据断言 |
| --- | ---: | ---: | ---: | ---: |
| `source-only` | 15 | 75/75 | 0 | 0 |
| `flat-index` | 15 | 75/75 | 0 | 0 |
| `state-projection` | 15 | 75/75 | 0 | 0 |

每个任务与条件组合均为 `n=3`，每组正确性均为 `15/15`。评分使用冻结 rubric 的五项标准：事实状态、当前动作、状态或范围边界、禁止结论与实际来源引用。45 份评分均为满分，逐次 Review 使用一次真实计时后按 45 个样本均摊的方式记录。

## 如何解释这个结果

这不是“状态投影已经证明比原始 Markdown 更准确”的结论。三个条件在这组小规模、合成且来源清晰的任务中都能恢复正确当前动作。

本轮更可靠地支持以下判断：

1. 当前记忆地图可以只投影状态、范围、关系与来源指针，而不复制原始正文。
1. 只提供原始记录或普通索引的条件，也可以在来源足够清楚时得到正确答案。
1. 因此，是否需要当前记忆地图取决于治理和审阅成本，而不能仅用这 45 次的正确率决定。
1. 当前地图仍必须回链原始来源；它不是第二份事实库，也不能代替冲突复验和人工批准。

## 人工探索性通道

单名参与者在 `state-table` 与 `visual-map` 两个条件下均答对 5/5 题。`visual-map` 耗时更长，并额外展开一次来源详情；该结果只有一名参与者和一轮任务，不能推断表格更高效、地图更慢，或任何视觉表达会普遍提高治理效率。

## 有效性限制

- 每个 Agent 任务与条件只有 3 次重复，不能建立稳定的效率、token 或调用次数排序。
- 夹具是合成资料，不覆盖真实项目的大规模历史、多人编辑、同步冲突或权限边界。
- 人工通道仅为单人探索性验证，不与 Agent 评分合并，也不作人群推广。
- 本报告只支持 macOS 上、当前模型与当前 CLI 版本下的结论。Win11 后续按 Level 2 执行 15 次兼容性 Smoke；通过后只能补充兼容性声明，不能替代独立正式复现。

## 公开产物边界

公开 POC 保留冻结夹具、状态生成器、校验器、运行器和本报告。私有目录中的 `raw.jsonl`、完整 `final.md`、`stderr.log`、`score.json`、人工逐题事件、本机路径与会话标识不进入 Git。
