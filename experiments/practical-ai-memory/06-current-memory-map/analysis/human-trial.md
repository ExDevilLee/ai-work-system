# 人工探索性实验记录

## 范围与边界

- 参与者：1 人。
- 条件：`state-table` 与 `visual-map`。
- 题目：每个条件 5 题，共 10 题；两套合成场景包以随机顺序呈现。
- 本报告只使用条件级脱敏汇总；逐题选择、题包分配、会话标识和浏览器事件仅保留在本地私有结果中。

## 完整性门禁

标准只读校验通过：`human result valid: conditions=2, questions=10`。

- 提交包含两个完成条件，每个条件均有 5 道完整题目记录。
- 不存在参与者身份字段、绝对路径或题外自由文本。
- 正式题包未出现在浏览器 Smoke 静态资源中。

## 条件级结果

| 条件 | 正确数 | 总题数 | 总耗时（秒） | 来源详情展开 | 改答次数 | 主观把握度（1-5） |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| state-table | 5 | 5 | 64.708 | 0 | 0 | 3 |
| visual-map | 5 | 5 | 137.580 | 1 | 0 | 3 |

## 解读限制

两种展示条件在本次单人探索中都答对了全部题目。`visual-map` 的耗时更长且出现一次来源详情展开，但这只是一次单人、不同合成题包和随机呈现顺序下的观察，不能据此推断地图增加理解成本、状态表更高效，或任一视觉表达对其他参与者更有效。

本结果没有显著性检验、没有跨参与者比较，也不与 Agent Pilot 的结果合并。它只证明本地人工实验链路可用，并为后续是否开展更大规模人工研究提供一个受控 checkpoint。

## 停止点

人工探索性实验与 Agent Pilot 均已形成脱敏 checkpoint。根据冻结协议，45 次 macOS 正式矩阵不会自动启动；是否冻结并执行正式矩阵仍需 Lee 确认。
