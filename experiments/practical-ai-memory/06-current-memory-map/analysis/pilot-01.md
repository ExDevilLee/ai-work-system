# macOS Agent Pilot 01 复核报告

## 范围与边界

- 平台：macOS。
- 规模：5 个冻结任务 x 3 个条件 x 1 次，共 15 次。
- 模型：`gpt-5.6-sol`；推理强度：`medium`。
- 本报告只记录 Pilot 的协议、来源和只读语义复核结果，不是正式矩阵结果。
- 私有运行目录中的原始事件、完整回答、标准错误、逐条评分和运行时路径均未写入本报告。

## 只读语义 Review

复核依据冻结的 `expected/answers.json` 与 `expected/rubric.json`，检查五个任务各自的当前动作、状态或关系边界、禁止结论和实际来源引用。15 条有效记录的建议结果如下。

| 任务 | source-only | flat-index | state-projection |
| --- | ---: | ---: | ---: |
| active-decision | 5/5 | 5/5 | 5/5 |
| superseded-rule | 5/5 | 5/5 | 5/5 |
| unresolved-conflict | 5/5 | 5/5 | 5/5 |
| scope-boundary | 5/5 | 5/5 | 5/5 |
| pending-observation | 5/5 | 5/5 | 5/5 |

所有建议均为 `protocol_valid=true`、`unsupported_claims=0`、`irrelevant_facts=0`。本阶段没有创建 `score.json`，也没有把 Pilot 当作正式评分或聚合证据。

## 条件观察

三个条件共享同一冻结事实和 Prompt；`flat-index` 未暴露状态或关系字段，`state-projection` 没有复制原始记录正文。Pilot 中三种条件均能完整恢复相应任务事实，不能据此宣称任一条件在质量上优于其他条件。

下表只保留每个条件 5 次 Pilot 的中位数，作为后续正式矩阵的审计参考：

| 条件 | 工作区读取调用 | 工作区输出字节 | 耗时（秒） |
| --- | ---: | ---: | ---: |
| source-only | 3 | 1,488 | 42.934 |
| flat-index | 3 | 1,687 | 69.077 |
| state-projection | 4 | 3,325 | 40.759 |

样本量仅为每组 5 次，且任务不同；这些描述值不支持稳定的效率比较或跨条件因果结论。

## 冻结候选与停止点

当前夹具、manifest、Prompt、预期答案、rubric、模型、推理强度和执行器版本可作为 macOS 正式矩阵的冻结候选。根据实验协议，正式矩阵不会自动启动：仍需 Lee 基于本 Pilot 报告及后续人工探索性实验 checkpoint 确认。
