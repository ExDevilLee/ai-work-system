# IG-803 Integrity gate rule

Version 1. Scope: project. Status: active.

Every backed-up file must pass a content-hash check against its
authoritative source manifest before the file is considered trustworthy
for restoration. A hash mismatch means the stored content has been altered,
corrupted, or replaced and must not be treated as a valid source. The
mismatch must be reported; the file must not be silently accepted.
