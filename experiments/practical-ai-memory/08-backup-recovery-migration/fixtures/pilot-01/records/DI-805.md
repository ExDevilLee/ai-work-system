# DI-805 Data retention rule

Version 1. Scope: project. Status: active.

Project-scoped operational data must be retained for thirty days after
last access, then archived for ninety days, then deleted. A derived
compact index summarising retention windows may exist for fast lookup,
but the index is a derivative of this rule, not an independent source.
The index must be rebuilt from the verified source after any restore
and must not be copied across devices as though it were authoritative.
