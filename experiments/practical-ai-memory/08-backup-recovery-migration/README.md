# 备份、恢复与迁移 POC

这是“AI 长期记忆实战”系列第八篇的实验入口。两个 macOS 请求配置已按顺序各完成 54 格
正式矩阵和全量只读 Review，合计 99/108 通过。不安排跨平台验证。

本 POC 不使用真实记忆、真实设备目录、账号、密钥、对象存储地址或私有运行记录。所有
夹具均为合成 Markdown 记录和相对路径 manifest。

## 要验证的问题

在同一套合成记忆源中，带完整性校验、恢复门禁和冲突停机规则的备份包，能否让 Agent：

- 区分可恢复、不可恢复和必须人工处置的情况；
- 保留来源、范围与版本边界，而不是把备份副本当成新的事实源；
- 在部分备份、哈希不匹配、目标端分歧或派生索引迁移时停止不安全动作；
- 明确派生索引应由已验证源文件重建，而不是跨设备复制。

它不验证真实云存储、真实双向同步、自动冲突合并、性能、成本或任何产品可用性。
